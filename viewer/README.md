# Warcraft III · OpenWar3

Этот запуск использует движок OpenWar3 0.4.11, написанный на TypeScript. WebGL рисует оригинальные карты и модели. Браузер читает ресурсы установленной игры с локального сервера по диапазонам байтов. Сервер привязан к 127.0.0.1 и принимает GET и HEAD. В проекте хранятся сценарии сборки и управления. Игровые ресурсы остаются в папке установленной игры.

## Сборка и запуск на Mac

Нужны Python 3, Node 24, npm и git. Из корня проекта:

```sh
python3 viewer/build.py
node viewer/serve.mjs
```

По умолчанию используется копия из `~/Library/Caches/warcraft3-original-web/extracted/app`. Другую папку можно передать первым аргументом, путь к собранному движку — вторым.

- [Первая глава Альянса](http://127.0.0.1:8886/) открывает Human01 в режиме Reign of Chaos.
- [Главное меню](http://127.0.0.1:8886/?local&edition=roc&patch=1.30.4) монтирует ту же копию игры.
- [Схватка на Booty Bay](http://127.0.0.1:8886/?local&map=BootyBay&edition=roc&race=human&airace=orc&ai=normal&fog=unexplored&patch=1.30.4) выбирает людей против орков на оригинальной карте.

В бою касание выбирает объект, удержание отдаёт контекстный приказ, движение пальца сдвигает камеру, два пальца меняют масштаб. Клавиатура и мышь работают через движок. В заставках сюжетный скрипт может временно взять управление камерой.

## Совместимость

Сборка закреплена на [e0530078](https://github.com/elevchyt/openwar3/tree/e0530078bb937e55b479c4d0286266ab955514f4). Сценарий использует исправления MDX и Lua из этого же коммита. Обёртка отключает автоматическую подмену графики и таблиц баланса, которую upstream применяет для совместимости версий. Ветка параметра `patch=1.30.4` задаёт базовый режим кода upstream, а физические файлы таблиц берутся из установленной копии. Распознавание голосовых команд исключено из сборки.

Это самостоятельная реализация игрового движка. Совпадение каждой миссии и всех кнопок с оригинальной игрой требует проверки на конкретных картах. Время загрузки и расход энергии на физическом Samsung надо измерить на устройстве.

## Что проверено на этой сборке

23 ноября 2026 года локальный Chrome загрузил Human01 из копии 1.31.1.12164 и запустил вступительную сцену. В мире было 186 игровых объектов типа «юнит». После пропуска сцены появился Артес с заданием «Defend Strahnbrad». Кнопки и характеристики героя отображались по-русски, а тексты внутри оригинального файла Human01 — по-английски. Русские таблицы этой копии используют UTF-8. Чтение этих таблиц проверено на загрузочном экране, кнопках меню и карточке Артеса.

Через сенсорные события Chrome удалось отдать Артесу приказ удержанием, сдвинуть камеру одним пальцем и изменить масштаб двумя. Его координаты после приказа изменились с (−2848, 1888) на (−2608, 1840). Кампания до конца и реальный Samsung пока не проверены.

До перехода к управлению героями Resource Timing зафиксировал 184 запроса к локальным файлам CASC, в сумме 318 486 081 байт (303,7 МиБ). В это число входит предварительная загрузка общих ресурсов. Голоса, музыка и следующие главы добавляют новые запросы. Этот объём характеризует первый запуск конкретной карты. В сцене остаются запросы двух второстепенных эффектов крови, для которых движок не находит модель по указанному пути.

На устройствах с сенсорным экраном без мыши включён ограничитель на 30 кадров/с. Для сравнения на Samsung добавьте `&fps=60` к адресу карты. Это ограничение частоты отрисовки. Экономия заряда на реальном телефоне ещё не измерялась.
