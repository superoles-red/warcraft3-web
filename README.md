# Warcraft III для мобильного браузера

Reign of Chaos и The Frozen Throne 1.31.1.12164 на русском языке. Движок OpenRealm работает в браузере через WebAssembly Memory64 и WebGL 2. Карты, сценарии, модели, текстуры, меню и звук берутся из локальной копии игры. Страница загрузки использует фон, логотип соответствующего издания, шрифт и шкалу из той же установки.

## Запуск на телефоне

**В домашней Wi-Fi-сети.** На подготовленном Mac откройте `run-phone.command`. Оставьте Mac включённым и откройте напечатанный адрес в Chrome на телефоне. Браузер покажет размер установки и загрузит полный комплект по частям. При прерывании загрузки уже сохранённые части используются при следующей попытке. Для повторного открытия домашнего HTTP-адреса нужен работающий сервер.

**С GitHub Pages и офлайн.** Скопируйте на телефон `local/Warcraft-III-1.31.1-ruRU-compact.zip`. Его можно получить по домашнему Wi-Fi, добавив `download/Warcraft-III-1.31.1-ruRU-compact.zip` к адресу сервера. Откройте опубликованную оболочку в Chrome и один раз выберите ZIP из загрузок. Браузер сохранит ресурсы на устройстве. После первого онлайн-запуска игру можно открыть без сети, в том числе с домашнего экрана через пункт установки приложения в меню Chrome. Публичный сайт содержит движок и загрузчик. [Reign of Chaos](https://superoles-red.github.io/warcraft3-web/) · [The Frozen Throne](https://superoles-red.github.io/warcraft3-web/?edition=tft) · [Выбор другого ZIP](https://superoles-red.github.io/warcraft3-web/?files)

**На Mac.** Откройте `run.command` или запустите `python3 server.py --open`. Подготовленный компактный пакет устанавливается по тому же сценарию, что и на телефоне. Для разработки при наличии только распакованных файлов сервер читает `local/gamedata` и `local/movies`. [Главное меню](http://127.0.0.1:8883/) · [Первая глава Альянса](http://127.0.0.1:8883/?map=campaign/human01.w3m) · [The Frozen Throne](http://127.0.0.1:8883/?edition=tft)

Первое касание в игре запрашивает полный экран. На широком экране движок открывает больше игрового поля и использует оригинальные боковые панели. В портретном положении кадр 4:3 помещается по центру. Касание выбирает юнита, удержание отдаёт приказ, свайп перемещает камеру, щипок меняет масштаб. При сенсорном вводе установлен предел 30 кадров/с. [Проверка пропорций и управления](docs/MOBILE-TEST.md)

## Состав компактного пакета

Полный ZIP занимает **808 250 839 байт (808,25 МБ)**. В нём 97 файлов кампаний из основного хранилища, три дополнительные сюжетные карты из русского демопролога, 203 карты для сражений и сценариев и все девять видеороликов. Чтобы сменить Reign of Chaos на The Frozen Throne, нажмите портрет справа от «Один игрок» в оригинальном главном меню. [Кампании и главы](docs/CAMPAIGNS.md)

Для коротких эффектов и реплик используется Opus. Длительные записи окружения используют IMA ADPCM, чтобы движок успевал распаковывать их при первом обращении. Сохраняются длительность, каналы и точки зацикливания WAV. Известные движку имена файлов сохранены. Оригинальные музыкальные MP3, интерфейс и игровые модели остаются в исходном формате. Видеоролики используют VP9 640 × 294 и стереодорожки на русском. [Размеры, кодеки и проверки](docs/ASSET-SIZES.md)

## Подготовка из своей установки

Понадобятся каталог с `.build.info` и `Data/`, Python 3.9+ с Pillow, Git, компилятор C/C++ и FFmpeg/FFprobe с libopus и libvpx-vp9. Для совместимого установщика Inno Setup сначала извлеките установку через innoextract. Все игровые файлы и производные сборки хранятся в игнорируемом каталоге `local/`.

```sh
python3 tools/prepare_game.py "/путь/к/установке"
python3 tools/prepare_movies.py --install "/путь/к/установке"
python3 tools/prepare_movies.py --native-webm local/movies --compact
python3 tools/audio_compact.py
python3 tools/prepare_presentation.py
# Если в установке есть DemoCampaignRUS.w3n, здесь подключите его по инструкции ниже.
python3 tools/make_pack.py --compact local/Warcraft-III-1.31.1-ruRU-compact.zip
python3 tools/make_distribution.py local/Warcraft-III-1.31.1-ruRU-compact.zip
```

Для включения трёх дополнительных глав из отдельного файла DemoCampaignRUS.w3n подготовьте их перед выполнением `tools/make_pack.py`. Расположение файла в установщике и команда извлечения описаны в разделе о кампаниях. [Подготовка русского демопролога](docs/CAMPAIGNS.md)

Для сравнения исходный полный веб-пакет можно собрать той же командой `tools/make_pack.py` без `--compact`, с другим именем ZIP. До включения трёх дополнительных миссий ZIP в этом режиме занимал 1 618 772 422 байта. Ранее собранный профиль первой главы Альянса занимает 457,66 МБ и включает только ресурсы этого прохождения. Загрузчик принимает и предыдущие пакеты.

Для публикации оболочки GitHub Actions выполняет `python3 tools/stage_shell.py --output site`. Список публикуемых файлов задан в `tools/shell_files.py`. Приватный сервер отдаёт манифест полной версии и части ZIP по 12 МиБ. Браузер проверяет размер и контрольную сумму каждой части перед записью в IndexedDB. Готовая установка заменяет предыдущую после проверки каталога ZIP.

## Происхождение

Для каталога «Сражения» движок связывает каталоги Maps и maps. Исправление инициализации лобби сохраняет его кнопки до запуска матча. Воспроизвести исправление на исходном файле WebAssembly можно командой `python3 tools/patch_lobby.py`. Проверен обычный запуск Booty Bay с компьютерным противником.
