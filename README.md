# Warcraft III для мобильного браузера

Оболочка загружает совместимый движок OpenRealm (wc3-wasm v0.1.0, WebAssembly Memory64 + WebGL 2) и читает ресурсы локальной установки Warcraft III. Эта версия проверяется на Reign of Chaos и The Frozen Throne 1.31.1.12164. Меню и игровой интерфейс рисует движок из графики игры. Первый выбор файла на публичном сайте использует системный диалог браузера.

## Запуск

На подготовленном компьютере откройте `run.command` или выполните `python3 server.py --open`. Сервер привязан к этому компьютеру. Обычный адрес открывает меню, прямая ссылка начинает главу без выбора в меню.

- [Главное меню Reign of Chaos](http://127.0.0.1:8883/)
- [Главное меню The Frozen Throne](http://127.0.0.1:8883/engine/?edition=tft)
- [Первая глава Альянса, «Оборона Странбарда»](http://127.0.0.1:8883/engine/?map=campaign/human01.w3m)

На телефоне откройте сайт в Chrome, выберите подготовленный игровой ZIP со своего устройства и дождитесь запуска. Файл сохраняется в IndexedDB этого браузера. Движок распаковывает запрошенные ресурсы из локального ZIP. Service Worker обслуживает потоковое чтение роликов. Смена пакета доступна по ссылке [выбора файла](https://superoles-red.github.io/warcraft3-web/?files). Для игры через публичный сайт требуется поддержка Memory64, WebGL 2, IndexedDB и Service Worker.

Касание выбирает юнита, удержание отдаёт приказ, свайп перемещает камеру, щипок меняет масштаб. На телефоне задан лимит 30 кадров/с. Разрешение рендера ограничено 1440 пикселями по длинной стороне. Автопрокрутка у края отключена, камера управляется жестами либо стрелками.

## Подготовка своей установки

Нужны локальная установка с `.build.info` и `Data/`, Python 3.9+, Git и компилятор C/C++. Для роликов нужен FFmpeg. Если исходные файлы упакованы в совместимый Inno Setup, сначала извлеките их в отдельную пустую папку через `innoextract`. Следующему шагу передаётся каталог, содержащий `.build.info`.

```sh
python3 tools/prepare_game.py "/путь/к/установке"
python3 tools/prepare_movies.py --install "/путь/к/установке"
python3 server.py --open
```

Для отдельной мобильной главы «Оборона Странбарда» выполните `python3 tools/make_human01_profile.py`. Она создаёт `local/Warcraft-III-Human01-mobile.zip` объёмом 457,66 МБ. После выбора ZIP игра откроет первую главу. Проверены старт, вступление и выдача приказов. Завершение главы и восстановление сохранения после закрытия вкладки требуют отдельного прогона.

Для полного частного ZIP после подготовки игрового дерева и роликов выполните следующую команду. ZIP можно скопировать на телефон кабелем. Подготовка сохраняет звук, модели, карты и текстуры из оригинала. Все извлечённые ресурсы и создаваемые пакеты хранятся в игнорируемом каталоге `local/`.

```sh
python3 tools/make_pack.py local/Warcraft-III-full.zip
```

## Происхождение сборки

SHA-256 исходного архива `wc3-web-v0.1.0.tar.gz` равен `233d7ab2bd74c1436fbf88780dc3cb0b9d093e0222f8eabf4bfdc895bc39391b`. В оболочке адаптированы размер кадра, управление камерой, чтение локального ZIP и показ роликов. Код загрузчика пропускает HTTP-запросы заведомо отсутствующих ресурсов по каталогу имён. Лицензии и уведомления поставщика находятся в `engine/`. Название Warcraft III и игровые материалы принадлежат Blizzard Entertainment.
